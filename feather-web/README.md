# Feather Design System

QOOE's themeable master design system. Products start from Feather and reshape it into their brand with
`brand/tokens.json` → `npm run brand`. The standard is in `../FEATHER.md`; versions in `CHANGELOG.md`.

- `npm run storybook` — browse every component; switch reference themes in the toolbar.
- `npm run manifest` — build Storybook and regenerate `foundation.json` (components, levels, slots, stories).
- `npm run build` / `npm run typecheck` / `npm test`.
