# Tokens

Every visual value in Feather resolves through three layers, and a brand file changes the first two:

1. **Primitives**: the palette and scales the engine derives from a handful of brand colors (the 4px grid, the six
   durations, the radius and shadow ladders, the font families).
2. **Semantic roles**: what a component actually reads. `--text-primary`, `--surface-hover`, `--border-primary`,
   `--primary`, `--destructive`, `type-heading-2`, `shadow-2`. A component never reads a raw color.
3. **Component tokens**: a brand's overrides for one `data-slot` (`"button"`) or one variant (`"button.outline"`).

Everything below is read from the **current brand's CSS variables**. Change the brand in the toolbar and it changes
here. A swatch that says "not in this brand" is a role the brand's schema does not define.

## Color roles

The text, border and focus roles are derived from the brand's own colors and each is checked against both the
background and the surface. The engine refuses a brand that cannot reach the floor (see **Accessibility floor**).

## Block, scrim, layer and opacity roles (feather-tokens/4)

A `/4` brand adds four **colour blocks** for coloured sections (`block-1` to `block-4`, each a surface and the ink that
reads on it at 4.5:1), a **media scrim** and the ink on it (for text over photographs and film), and its default
**loudness**. Layers (`--layer-*`) and opacity roles (`--opacity-*`) are house constants, the same in every brand.
A brand written before `/4` shows these roles from the house defaults.
